# Nehemiah 3 — One Wall, Many Hands

An interactive study guide with a Jerusalem reconstruction map, a 41-stop walkthrough,
57 selectable locations, nine AI illustrative district scenes, the supplied NIV chapter, and a chapter overview.

Open `index.html` in a current browser. No build or external dependencies are required.

Map: [Bible Mapper Atlas](https://biblemapper.com/blog/index.php/2026/02/16/poster-map-of-jerusalem-in-the-time-of-nehemiah-circa-445-b-c/).
The map is one proposed reconstruction; location identifications and highlight extents are uncertain.

Scripture: The Holy Bible, New International Version NIV. Copyright 1973, 1978, 1984, 2011 by Biblica, Inc.
All rights reserved worldwide. Map and Scripture retain their respective copyrights.

The scene gallery adds later artistic interpretations by Gustave Doré and James Tissot,
and a modern photograph of the excavated Broad Wall. See IMAGE-CREDITS.md for sources,
licenses, and the distinction between artistic imagination and archaeology.
